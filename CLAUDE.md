# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

ERGMRank.jl is a Julia port of the R `ergm.rank` package (from the StatNet collection) for fitting Exponential Random Graph Models to rank-order networks, where each actor assigns ordinal ranks to a subset of other actors.

## Architecture

The entire package lives in a single source file: `src/ERGMRank.jl`. It is organized into these sections:

1. **RankNetwork** -- dense `Matrix{Int}` of rank values; row i = ego i's ranking of the alters, GREATER value = HIGHER standing (ergm.rank convention). The complete-ranking invariant (each row's off-diagonal is a permutation of `1:(n-1)`) is validated at construction (`RankNetwork: not a valid complete ranking — ego i's ranks … are not a permutation of 1:(n-1)`), preserved by `swap_ranks!` (the AlterSwap move), and checkable with `is_valid_ranking`. `as_rank_network(mat)` refuses a matrix with `missing`/`nothing` (a rank has no face value, so there is no `missing=` policy to offer — the message points at the NetworkCore.jl missing-data guide) and non-integer values, with `ArgumentError`s that say so.

   **`as_rank_network(net::Network; attr=:rank, missing=:error, report=false)` is the `Network`→`RankNetwork` adapter of the ecosystem conversion contract** (R's `as.matrix(nw, attrname="rank")` on `newcomb`). It preserves the actor set and the ranks (edge attribute `attr` on every arc `i → j`); REJECTS with an `ArgumentError` that says why an undirected network (rankings are ego-specific), a two-mode network, a masked dyad (`require_observed(net, :error; context="as_rank_network", face_ok=false)` — `supports_missing(as_rank_network) == true`, `missing_policies(as_rank_network) == (:error,)`; `missing=:face` is refused with the reason: an unobserved rank has no face value to condition on, so `:face` is deliberately NOT offered and the guard's error must not suggest it), an arc without a rank, a non-integer rank and an ego whose ranks are not a permutation (the message names the ego AND the attribute, reusing `_ranking_violation`); and with `report=true` returns `(rnet, ConversionReport(:Network, :RankNetwork))` with one `record_drop!` per other edge attribute, vertex attribute, network attribute and self-loop arc. The adapter testset is the citation of the `Network`→`RankNetwork` column in `NetworkCore.jl/docs/src/guide/conversion_invariants.md`. Do not add a `:face` policy here; do not read a masked arc.

   **Display** follows NetworkCore.jl's convention: two-arg `show` is the ONE-LINE form (`RankNetwork(4 actors)`, `RankERGMModel(1 term, 4 actors, CompleteOrder)`, `RankERGMResult(swap-MPLE, 2 terms, converged)` — what `print`/`string` and containers use, so a `Vector{RankNetwork}` of draws prints one line per element), and the block (rank matrix up to 12 actors; the R-style results table) is the `MIME"text/plain"` method the REPL calls. Tests that assert on the block use `sprint(show, MIME("text/plain"), x)`; never put the block back in the two-arg method.
2. **Reference measure** -- `CompleteOrderReference`: discrete-uniform over complete orderings (constant; cancels from likelihood ratios; the constraint is what matters).
3. **Terms** -- `RankDeference`, `RankNonconformity(:all/:localAND)`, `RankNodeICov`, `RankInconsistency`, `RankEdgeCov`. **Provenance (stated in the source; the package is MIT):** the `compute` methods and the `weights`/`wtcenter` handling of `RankInconsistency` are an independent implementation of the term definitions (Krivitsky & Butts 2017; ergm.rank's term help pages; the docstrings), written without consulting ergm.rank's code. **Never open ergm.rank's C or R term source (`wtchangestats_rank.c`, `InitWtErgmTerm_rank.R`) to change them**: work from the definitions and compare with R by output only (fixtures). `compute(:all)` counts, for each ordered alter pair, the egos that put the first above the second and multiplies by the rest (O(n³)); the covariate terms weight each alter by Σ sign(y[ego,a] − y[ego,b]); the "Summary statistics equal a literal enumeration of their definitions" testset pins every `compute` (and the weights) to a tuple-by-tuple enumeration, on valid and on tied rankings. The `swap_change` methods are derived independently from the term definitions as a swap move, which has no counterpart in ergm.rank's single-cell change functions; they use the definitions' notation (ego i, alters j, k, l; the local nonconformity summand `1[y_il > y_ij]·1[y_il > y_ik]·1[y_lj > y_lk]·1[y_ik ≥ y_ij]` with its factors in the order the definition reads), and the same rule as `compute` applies: never open ergm.rank's source to change them. They are golden-master tested against R ergm.rank 4.1.2 through the PROVENANCED fixture `test/fixtures/rank_terms.toml` (generated by `test/fixtures/r/rank_terms.R`, a `summary()` call: all six statistics on the 4-actor README network and on a seeded 8-actor ranking with frozen covariates/reference, `check_golden` at 1e-9 — never bare literals). **`RankInconsistency(ref; weights, wtname, wtcenter)`** is ergm.rank's full `rank.inconsistency`: `weights` an `n×n×n` array or a function `(i, j, k)`, built by `_inconsistency_weights` with R's documented semantics, confirmed by output (function → triples of distinct actors, NA elsewhere; `wtcenter` subtracts the mean of the non-NA entries; NA → 0; `NaN`/`missing` are R's NA), stored as `weights::Union{Nothing,Array{Float64,3}}` with the name in `label` (`rank.inconsistency:<wtname>[c]`). Pinned at 1e-9 against R's `summary()` by `test/fixtures/rank_inconsistency_weights.toml` (function and array weights, centred and not, an array with NA cells); the weighted `swap_change` is pinned to the brute-force oracle, NOT to R's MCMC change statistic for this term, which tests the same comparison weight twice and so skips comparisons it should not (noted in the fixture script). `RankNodeICov(:age)`/`RankEdgeCov(:x)` (ERGM.jl's attribute-name spelling) are refused by dedicated constructors that say to pass the values (`vertex_attribute_vector(net, :age, Float64)`), since a `RankNetwork` carries no attributes. **Known limitation, stated everywhere (README, terms guide, docstring, CHANGELOG):** ergm.rank's `rank.nonconformity` `local1`/`local2`/`geometric`/`thresholds` variants are NOT implemented; the constructor refuses them with `RankNonconformity: variant must be :all or :localAND (got :local1); ergm.rank's local1/local2/geometric/thresholds variants are not implemented in ERGMRank.jl` (the exact text is pinned) — never fall back to `:all` silently. A wrongly sized covariate is refused by BOTH `compute` and `swap_change` with a message naming the term (`_bad_nodeicov_length`, `_bad_matrix_size`), so the fitter, the sampler and `gof` all say the same thing. **The term contract: every term implements `compute(term, rnet)` AND `swap_change(term, rnet, ego, j, k)`** (exported) — the change `g(y_swapped) − g(y)` when ego swaps its ranks of j and k. A swap changes ego's comparison of exactly the alter pairs containing j or k, so `_sum_changed_pairs(f, y, n, ego, j, k)` visits those ordered pairs once with `d = ±1` and each term supplies the multiplier (deference: the two off-row factors; nodeicov/edgecov: the covariate difference; inconsistency: agreement with the reference flips); the nonconformity variants additionally loop over the matched actor (`:all`) or enumerate the triples containing j or k (`:localAND`) — O(n) and O(n²) respectively, 0 bytes, never a recomputation of a full statistic. **There is no brute-force fallback method**: `_swap_delta_bruteforce` (two `compute`s, swap and restore) is the TEST ORACLE only, and every `swap_change` is asserted `==` to it (exact — integer counts, integer-valued covariates in the tests) on 200 random cases at n ∈ {4, 5, 8} and on every swap of the 4-actor R network. `_swap_delta!(delta, terms::Tuple, rnet, ego, j, k)` fills the kernel's workspace with one `swap_change` per term, `@generated` over the tuple type (ERGM's `_change_stat_tuple` pattern — no `map` cliff at 32 terms), 0 bytes pinned at p = 2 and p = 8; `_swap_delta` is the allocating convenience form. Adding a term means adding both methods and a row in the oracle testset.
4. **Estimation** -- `fit_ergm_rank` (alias `ergm_rank`, the statnet-style name; the pre-release `fit_rank_ergm` binding and the short positional `RankERGMResult` constructors never shipped and are deleted) with **`method=:mcmle` (the DEFAULT — R ergm.rank's estimator; the statnet-style name must mean what it means in R)** or `method=:mple`. The main method is `(rnet::RankNetwork, terms::Vector{<:AbstractERGMTerm}; kw...)`; a single term and a tuple forward to it, a `Network`/`AbstractMatrix` first argument throws `_not_a_rank_network` ("call as_rank_network(...) first"), and `_check_rank_terms(context, terms)` refuses any term without BOTH `compute(t, ::RankNetwork)` and `swap_change` methods (ERGM.jl's binary terms) up front, from the fitter and `simulate_rank_ergm` alike — never a `MethodError` from the design builder. **The two are different estimators, and `RankERGMResult.method` says which one a result is** (`objective` answers `:likelihood`/`:pseudolikelihood`; `is_exact` is `false` for both, for two different reasons stated in its docstring). `maxiter` caps the MCMLE iterations (60, R's `MCMLE.maxit`) or the Newton iterations (100); `se` resolves per method (`:fisher` vs `:hessian`/`:bootstrap`) and is validated by `NetworkCore.check_se` against that method's tuple; `se=:hessian`/`:bootstrap` without `method=:mple` is refused with a sentence saying to pass it. Tests and examples that exercise the swap-MPLE machinery say `method=:mple` explicitly.

   **Swap-MPLE inference is withheld by default (ERGM.mple's pattern; there is no exempt case, because no rank model is "dyad-independent").** `se` not given under `:mple` → `se_type == :hessian` with `inference_withheld == true` (the 15th of `RankERGMResult`'s 17 fields; `separated_terms` is the 17th): `_z_and_p` returns `NaN` z/p for every finite coefficient (a boundary `∓Inf` keeps z = ∓Inf, p = 0), `show` prints the "z values and p-values are not reported (NaN)" note, `confint` throws an `ArgumentError` built from the ONE sentence `_WITHHELD_NOTE`, which `approximations` also lists. An explicit `se=:hessian` is the written opt-in to the naive Wald table (`inference_withheld == false`, the anticonservatism warning printed); `se=:bootstrap` reports z/p/intervals. Measured (scratch `coverage.jl`, n = 10, 300 replicates, 95 % Wald): pseudo-Hessian coverage 0.59/0.77 and 0.48/0.64, bootstrap 0.95/0.97 and 0.98/0.99, MCMLE 0.96/0.95 and 0.96/0.98 — quoted in the estimation guide; do not re-enable default p-values.

   **`method=:mple`**: swap-based maximum pseudo-likelihood — for each ego and unordered alter pair, the observed relative order is logistic in θ'[g(y) − g(y_swapped)]. **Everything shared comes from NetworkCore.jl by name and is never re-implemented here:** the optimizer `NetworkCore.newton_fit` and kernel `NetworkCore.logistic_derivatives` (`public`; `ERGM.newton_fit === NetworkCore.newton_fit`, pinned), the floored z→p helper `NetworkCore.z_pvalues` (there is no `_z_pvalues` in this package — `@test !isdefined(ERGMRank, :_z_pvalues)`), the `se=` validator `NetworkCore.check_se`, the coefficient table `NetworkCore.CoefficientTable` (`coeftable(fit)` IS what `show` prints), and the bootstrap loop `NetworkCore.bootstrap_cov`. **Claim discipline:** this is NOT the MCMC MLE and must not be described as a "consistent" approximation to it — the swap comparisons multiplied into the pseudo-likelihood are not independent, and no asymptotic regime under which swap-MPLE is consistent has been established here. Nor does the pseudo-likelihood EVER coincide with the likelihood — not even for a term that decomposes over egos (there is no rank analogue of dyad independence: an ego's comparisons must form a total order): on the 4-actor network with `RankNodeICov([1,2,3,4])` exact enumeration of the 1296 orderings gives the MLE −0.0767 while the swap-MPLE is −0.0880 (the default MCMLE lands on the exact MLE up to Monte-Carlo error: ten seeds, mean within 4 MC standard errors, none equal to its swap-MPLE start — the "Default estimator is the MCMC MLE and always takes a step" testset), pinned by the nested testset in the n = 4 enumeration testset. **The gap to the MLE is model-dependent** — 0.30/0.43 MLE-SE on the week-1 two-term fixture, 0.89/0.83/0.76 on the week-2 three-term fixture (`newcomb2_rank.toml`, asserted > 0.5); never quote the week-1 numbers as if they were general. Each factor is the two-state conditional `P(y | {y, y_swapped})`, not "the order of j and k given the rest of the rankings" (a non-adjacent swap reorders j and k relative to the intermediate alters); say it that way. The pseudo-Hessian SEs are anticonservative under dependence (see the default-inference paragraph above); say so wherever the estimator is documented.

   **The swap-MPLE can fail to exist, and every failure is loud** (warning at fit time + `approximations(fit)` entry + a line under `Converged:` in `show`; the three are derived from the same fields so they cannot disagree):
   - *Boundary statistic* (R's `drop=TRUE`): the design's response is identically `true`, so a column whose nonzero swap differences share one sign is at the boundary of its attainable range (`:min` → the observed ranking minimises it over every single swap, e.g. `RankInconsistency(rnet)` on `rnet`; `:max` → maximises it). `_rank_mple_fit` seeds `ERGM.Extension.boundary_columns(D, ones(m), ones(m); fixed=extreme)` with `ERGM.Extension.extreme_statistics(terms, rnet)` (the terms whose observed value is an end of their `ERGM.Extension.attainable_range`, declared by this package's methods of that generic on a `RankNetwork`: counts — deference, both nonconformity variants, the unweighted or non-negatively weighted inconsistency — have the lower bound 0; covariate terms none; ergm.rank declares no bound, so this is the ERGM.jl convention, not ergm.rank output), so a count observed at 0 is fixed even when no swap changes it; warns with `ERGM.Extension.warn_boundary` (noun "swap comparisons", note "ergm.rank's swap pseudo-likelihood has no drop"), and then fits with **`ERGM.Extension.mple_fit_design(D, ones, ones, names; extreme=boundary, noun="swap comparisons", warn=false)`** — ERGM.jl's ONE pseudo-likelihood fitter (drop → aliasing → Newton → separation verdict); there is no local drop or Newton code, and the fit's returned `fitted`, `kept_rows`, `aliased` and `verdict` are used as they are (the separation warning reads `r.verdict`; no second `logistic_separation` call). Coefficient fixed at `∓Inf`, SE 0 (z = ∓Inf, p = 0), `dof = count(isfinite, coef)`, `n_kept` recorded and used by `bic`. If every row is touched, the remaining coefficients are **NaN, `converged = false`, "not identified"** (`unidentified` in the return), loglik NaN; with no coefficient fitted but rows left, loglik is `n_kept·log(½)`. `drop=false` (R's `control.ergm(drop=)`) refuses any boundary with `_refuse_no_drop` before fitting. `se=:bootstrap` is refused with an `ArgumentError` when a coefficient is fixed.
   - *Aliased statistic*: a column of zeros (no swap changes the statistic, e.g. `RankNodeICov(ones(n))`) or one in the span of the preceding columns is `NaN` with SE `NaN` (R's `NA`), warned by `_warn_aliased_rank`, noted by `_unidentified_note` in `show`/`approximations`; the fit stays `converged` and the other coefficients equal the fit without the term (pinned exactly). It used to stall every coefficient at 0.
   - *Separation the column test cannot see* (a combination of statistics no single swap lowers): decided by NetworkCore's exact verdict on the design actually fitted, computed once inside `mple_fit_design` and returned as `r.verdict` (after a boundary drop: the kept rows and columns), never from where Newton stopped — the 4-actor R test network under `RankDeference() + RankNonconformity()` IS such a design (direction (1, 1) gives Dβ ≥ 0 on every row; the baseline reported θ ≈ (9.4, 10.1), SE 7,066, `converged = true`). The ecosystem's separation policy applies: `_rank_mple_fit` warns through `NetworkCore.warn_separation` (estimate "swap-MPLE", `_SEPARATION_NOTE` quoting R's "The MPLE does not exist!"), `converged = false`, the terms go to `fit.separated_terms`, `_z_and_p` gives NaN everywhere, `confint` returns NaN (before the withheld refusal), `se=:bootstrap` is refused, and the caveat is `separation_caveat(terms)`. `ERGM._separated` is no longer used (the reach-in testset asserts it). **Tests that only need "a well-posed two-term model" use `well_posed_network()` (6 actors), not `r_test_network()`.**
   - *Newton exhausting `maxiter`*: `converged = false`, warning quotes the gradient norm (`grad_norm` in the `_rank_mple_fit` return).
   - *Rounding-level stalls*: on a 2,040-row design (Hessian entries in the thousands) Newton stalls at the maximum with ‖∇ℓ‖ ≈ 5e-4, below the objective's rounding floor but above `sqrt(tol)`; `NetworkCore.newton_fit` now declares convergence on the scale-free Newton decrement ½∇ℓ'(−H)⁻¹∇ℓ < tol (adopted at ERGMRank's request), so the local `_stalled_at_optimum` shim and its testset are deleted and the testset "newton_fit converges on the swap design without a local shim" pins the kernel's verdict on the Newcomb design directly.

   **Robust SEs** (`se_type` on `RankERGMResult`, reported by `NetworkCore.se_method`): `se=:bootstrap` is a **parametric bootstrap** — simulate `n_boot` rank networks at θ̂ with the AlterSwap sampler (`simulate_rank_ergm`), refit the swap MPLE on each (`_rank_mple_fit` with `warn=false` is the shared core), empirical covariance — with the same API as `ERGM.mple`'s (`n_boot`/`boot_burnin`/`boot_interval`/`rng`), running on the ONE shared `NetworkCore.bootstrap_cov` loop; never paste the loop in. A replicate without a finite refit (∓Inf/NaN/separated) is a NaN row of `fit.boot_replicates`, **excluded** from the covariance (ERGM.mple's pattern; the warning, `show` and `approximations` carry the ecosystem's sentence `_BOOT_EXCLUSION_BIAS`: the excluded replicates are the extreme ones, so the standard errors are biased downward), warned about once and recorded in `approximations`; fewer than 2 finite refits throws. The point estimates are identical under both; only the covariance changes. On the test fixture the bootstrap SEs are more than **2× larger** than the Hessian ones — this package is where the anticonservatism bites hardest, because *every* rank fit has overlapping comparisons and there is no exact special case to exempt. `show`/`approximations` read `se_type` and drop the anticonservatism claim when a bootstrap was used, but keep the point-estimate caveat (swap pseudo-likelihood, not the MCMC MLE, no consistency claimed) in both — `is_exact` stays unconditionally `false`. **The replicates are thinned by ESS**: with the default `boot_interval`, `_simulate_thinned` (shared with `gof`) measures the effective sample size of the model statistics over the draws (`ERGM.mcmc_convergence(...).n_eff`, the Geyer estimate; needs ≥ 20 draws) and, below `n/2`, redraws once at an interval scaled by `n/ESS` (≤ 8×); below `n/4` it warns. An explicit interval is honoured. On Newcomb the default interval gives lag-1 autocorrelations 0.2/0.5 of the statistics (ESS ≈ 0.29 n) and the adapted interval is 4× longer.

   **StatsAPI surface**: all ten verbs (`coef`, `stderror`, `vcov`, `confint`, `loglikelihood`, `nobs`, `dof`, `aic`, `bic`, `coeftable`) plus `coefnames` (the term names, `== coeftable(fit).names`, a fresh vector), pinned by `NetworkCore.check_statsapi(fit; required=(STATSAPI_VERBS..., :coefnames), strict=true)` for both methods. **`nobs` is per method**: the `n(n−1)(n−2)/2` swap comparisons under `:mple` (its observations) and R's `nobs.ergm` = `network.dyadcount` = `n(n−1)` under `:mcmle` (`_n_dyads`; `n_kept` of a `:mcmle` result is that too, so `bic` is on R's scale — `log(272)` on Newcomb, not `log(2040)`). Under `:mple`, `aic`/`bic` are the **pseudo**-AIC/BIC of the swap pseudo-likelihood (`bic` uses `n_kept`), not comparable to R's bridge-sampled `logLik`, and **NaN when `n_kept == 0`** (every comparison changes a dropped boundary statistic — `show` prints "not defined", never the `0.0` of an empty product); under `:mcmle` they are the AIC/BIC of the bridge log-likelihood (`NaN` with `bridge_rungs=0`). **The log-likelihood convention**: `loglikelihood` of a `:mcmle` fit is ABSOLUTE (θ̂'g − log Z(θ̂), `log Z(0) = n·log((n−1)!)` exact); R's `logLik` is RELATIVE to θ = 0 (ergm defines a valued model's null likelihood as 0), so `R = loglikelihood(fit) + n·log((n−1)!)` and AIC/BIC shift by `−2n·log((n−1)!)` (≈ 1042 on Newcomb). Stated in the `aic`/`bic` docstring, the estimation guide, the README and the migration table, and asserted against R's `logLik` by the fixture — never claim the numbers "are R's". Keyword vocabulary: `maxiter`, `n_sim`, `rng` (pinned via `Base.kwarg_decl`; never `max_iter`/`n_sims`/`seed`), and the MCMLE keywords are `ERGM.mcmle`'s, spelled the same (pinned against `Base.kwarg_decl(ERGM.mcmle)`).

   **`method=:mcmle` (the default)** — the MCMC MLE, the estimator of R `ergm.rank`, in `_rank_mcmle`. **It is `ERGM.mcmle`'s iteration with the AlterSwap chain as the sampler, and nothing statistical is re-derived here**: the swap-MPLE start (`_rank_mple_fit` with `warn=false`). **A statistic at an end of its attainable range (`_rank_extreme_statistics`) is refused by `_refuse_extreme_mcmle`, with or without `init=`**: R's drop would hold the statistic at its bound, but the rankings sharing an extreme value are not swap-connected (4 actors: nonconformity 0 = 24 isolated rankings, local nonconformity 0 = 138 rankings in 22 swap classes — pinned by enumeration in "Attainable-range extremes"), so a held AlterSwap chain would fit a smaller model; `drop=false` gives the strict-mode message. A design-only boundary start (extreme among the single swaps but not at the attainable bound) is refused unless `init=` is given — then warned about, because a swap-local extremum is not proof that no MLE exists; an unidentified (NaN) start and a separated start are refused pointing at `init=`; **the iteration itself is ERGM.jl's public `_mcmle_solve`, CALLED** (`draw(θ, n)` = `_rank_mcmc_sample`, `target = obs_stats`, `context = "fit_ergm_rank(method=:mcmle)"`): the Hummel step, the stopping rule — `termination=:confidence` by default, R ergm 4's equivalence test on the updated coefficients with its sample-size boost up to `max_n_samples` (16·`n_samples`); `:hotelling` selects the fixed-sample t-ratio + Hotelling rule of `ERGM.mcmc_convergence` — the singular-covariance stop, the step at EVERY iteration (the converged θ̂ is the update from the sample that passed, which is the final sample; an unconverged fit draws a fresh one), and the Fisher + Monte-Carlo covariance (`stderror` includes the MCMC error; `show` prints R's "MCMC %" via `_mcmc_percent`, `fit.vcov_fisher` is V alone). **Never paste the loop, the γ rule, a stopping test or a quadrature back here**: the "Entry points and keyword vocabulary" testset asserts the source calls `ERGM.Extension.mcmle_solve(` and `ERGM.Extension.bridge_integrate(` and contains no `ERGM._hummel_step(` or `quantile(Chisq`. The result records `termination = (rule, p_value, precision, confidence, n_samples)` (16th field, as `ERGMResult`), printed under `Converged:` and quoted by the non-convergence warning/caveat; `mcmc_convergence` is the `ERGM.MCMLEConvergence` of the final sample under either rule. **The sampler** is `_rank_stats_chain`: the ONE kernel `mh_toggle!` with the ONE proposal `_propose_swap` (shared with `simulate_rank_ergm`, same draw order), `change!` = `_swap_delta!`, `apply!` = `swap_ranks!` **plus `stats .+= delta`** — the running statistics are kept current from the accepted swap's change statistics, and `on_sample` copies them into a row: no `compute` per draw. `_rank_mcmc_sample` is `ERGM._mcmc_sample`'s contract: one chain on the caller's `rng`; `n_chains > 1` splits the draws (first `n_samples % n_chains` chains get one extra), draws one `UInt64` seed per chain from `rng` in order, runs each on `Threads.@spawn` with its own `Xoshiro(seed)` and concatenates in chain order — so a fit depends on `rng` and `n_chains` only, never on the thread count (`n_chains` must never default to `Threads.nthreads()`); the reproducibility testset pins bit-identity for the same `rng`, chain by chain against the seeds. **The log-likelihood** is `_rank_bridge_loglik`: θ̂'g_obs − [log Z(θ̂) − log Z(0)] − log Z(0) with `log Z(0) = n·log((n−1)!)` exact (`_log_n_orderings`) and the ratio by path sampling along θ_u = u·θ̂ (`_rank_bridge_logZ_ratio`: ERGM's public `_bridge_integrate` — composite Simpson over `bridge_rungs` segments, an odd count raised by one — with this package's sampler as the `mean_stats(θu, k)` callback, one seeded chain per grid point on its own task — `ERGM._bridge_logZ` with the uniform ordering model as the exact reference; θ̂ = 0 returns 0 without drawing). It runs after the final sample, so coefficients and SEs are bit-identical with `bridge_rungs=0` (then `loglik`/`aic`/`bic` are `NaN`, `show` says "not estimated", `approximations` records it — ERGM's policy). The n = 4 testset enumerates all (3!)⁴ = 1296 orderings and checks the bridge against the exact log-likelihood at θ̂ (< 0.05 at 32 rungs), the MCMLE against the exact MLE (< 0.25 SE) and `vcov_fisher` against the exact Fisher information. **Non-convergence is loud** in the ERGM pattern: `converged || @warn` after the loop quoting max t-ratio / Hotelling p / γ, `_nonconvergence_caveat` for `:mcmle` quotes the same numbers from `fit.mcmc_convergence`, printed under `Converged: false` and listed in `approximations`. Threaded chains and bridge rungs run through NetworkCore's public `spawn_all` (no local copy; `!isdefined(ERGMRank, :_spawn_all)` is pinned), which waits for every task and rethrows the first failure as the task's OWN exception (an `ArgumentError` stays an `ArgumentError`, never a `TaskFailedException`).
5. **Simulation** -- `simulate_rank_ergm`: Metropolis with the symmetric AlterSwap proposal on the ONE shared kernel `ERGM.mh_toggle!` — the move is `(ego, j, k)`, `change!` fills the kernel's `delta` with `_swap_delta!` (the per-term `swap_change`, O(n)–O(n²) per step) and returns `false` (a swap has no removal direction), `apply!` is `swap_ranks!`, `on_sample` pushes `copy(current)`. The sampled sequence is **bit-identical** to the pre-kernel, brute-force loop (same rng consumption order; one testset re-runs that loop verbatim with `_swap_delta_bruteforce` and compares, another pins five draws as literals recorded before the change) and a step allocates 0 bytes (doubling the burn-in adds exactly 0 bytes, pinned). **Burn-in/interval defaults are swap-scaled**: `burnin=nothing`/`interval=nothing` on `simulate_rank_ergm`, `gof` and `fit_ergm_rank`'s `boot_burnin`/`boot_interval` resolve through `_resolve_mcmc_controls(rnet, burnin, interval)` → `_mcmc_defaults(rnet) = ERGM.Extension.mcmc_defaults(_n_comparisons(rnet))` (`public` in ERGM): `20 n_swaps` and `max(100, n_swaps ÷ 10)` with `n_swaps = n(n−1)(n−2)/2`, the rank analogue of the dyad count; an explicit integer is honoured. `n_sim < 1`, fewer than 3 actors and a θ/terms length mismatch are refused. **So is a non-finite coefficient** — `_check_finite_coefficients(context, terms, θ, fitted)` runs in `simulate_rank_ergm(rnet, terms, θ)`, `simulate_rank_ergm(fit)` and `gof(fit)`: a coefficient fixed at ±Inf by a boundary statistic or NaN (not identified) makes θ'Δ non-finite at every proposal, so the kernel would reject every swap and return copies of the starting ranking, which `gof` would print as a perfect fit (every simulated statistic equal to the observed one, MC p-value 1). The `ArgumentError` names the fixed and the NaN terms, points at `fit.converged`/`approximations(fit)` and at removing the term (R's `drop=TRUE`) — the same refusal as `se=:bootstrap`. Never let the sampler run at a non-finite θ.

## The swap MPLE is a logistic regression, and its loop is NetworkCore.jl's

The swap pseudo-likelihood **is** a logistic likelihood on the swap-difference rows `d = g(y) − g(y_swapped)` with the response identically `true` — the observed order is always the "success". So `_rank_mple_fit` carries no loop of its own (it used to: `hess .-= (pr*(1-pr)) .* (d * d')`, a fresh `p×p` outer product on every one of the `n(n−1)(n−2)/2` comparisons of every Newton evaluation, **229 KB and 0.20 ms per evaluation** on a 17-actor ranking). It builds the design with `_rank_design(terms, work)` — one dense `(comparisons × p)` matrix filled in place by `_rank_design!(D, Tuple(terms), work)` behind a function barrier, every row one statically dispatched `_swap_delta!` (the per-term `swap_change`: the 2,040-row Newcomb design takes 15 ms, was 1.0 s with brute-force differences; allocations ≤ `8·m·p + 4096` bytes, pinned) — and hands it to the shared **`NetworkCore.logistic_derivatives(D, trues(size(D, 1)))`**, the same builder ERGM's MPLE, ERGMMulti's MPLE and TERGM's CMPLE run on: **192 bytes and 0.046 ms per evaluation**, 4.3x faster, allocations independent of the comparison count. **Never paste the loop back in**; if it needs a feature, add it to `NetworkCore.logistic_derivatives`. An `@allocated` regression test pins the bound, and a companion test asserts `logistic_derivatives(D, trues(...))(θ̂)` reproduces `fit.loglik` — i.e. that the all-true logistic really *is* the estimator, not merely similar to it.

## Golden fixtures (statnet ergm.rank)

Four fixtures, all loaded with NetworkCore.jl's `load_golden`:

- `test/fixtures/rank_terms.toml` (`test/fixtures/r/rank_terms.R`, seconds): every term's `summary()` value on the 4-actor network and a seeded 8-actor ranking — the term formulas' golden master (see Terms).
- `test/fixtures/rank_inconsistency_weights.toml` (`test/fixtures/r/rank_inconsistency_weights.R`, seconds): the weighted `rank.inconsistency` on the same two rankings (see Terms).
- `test/fixtures/newcomb2_rank.toml` (`test/fixtures/r/newcomb2_rank.R`, ~20 min): the week-2 three-term MCMLE (see below).
- `test/fixtures/newcomb_rank.toml`, generated by `test/fixtures/r/newcomb_rank.R` (**slow — ~17 min**: a rank-ERGM MCMLE takes ~3 minutes and the script does six, for the replication study). Model: `newcomb[[1]] ~ rank.deference + rank.nonconformity("all")`, `reference = ~CompleteOrder`. It also freezes R's `logLik` (`mle_loglik`, RELATIVE to θ = 0), its MC standard error (`mle_loglik_mc_se`, `attr(logLik(fit), "vcov")`), `mle_df`, `mle_nobs` (272), `mle_aic`, `mle_bic`, `mle_std_errors_rel_sd` (R's relative SE spread over its five replication seeds), and in `[tolerance]` `loglik_sd_multiple = 4`. **`newcomb_week1()` (exported) is that ranking verbatim**, embedded in `src/` with its provenance comment, and the "newcomb_week1 is the fixture's ranking" testset asserts the identity — change one and the other must follow. (`NetworkCore.load_dataset(:newcomb)` has been requested cross-repo.)

**Two estimators, two kinds of assertion.**

- **`method=:mcmle` (the default) IS ergm.rank's estimator and is ASSERTED against it**, on two fixtures:
  - `newcomb_rank.toml` (week 1, `rank.deference + rank.nonconformity("all")`): run at ergm.rank's own budget, parsed from the fixture's `provenance.mcmc_control` (`n_samples=2048, burnin=8192, interval=512`, one chain), on two Julia seeds — seed 1 with `bridge_rungs=16, bridge_samples=512`, asserting `loglikelihood(mle) + 17·log(16!)` against `mle_loglik` within `loglik_sd_multiple × √2 × mle_loglik_mc_se` plus `nobs == mle_nobs`, `dof == mle_df` and the AIC/BIC shift; seed 2 with `bridge_rungs=0` — and asserts `|coef − mle_coefficients| ≤ coefficient_sd_multiple × √2 × mle_seed_sd` (and the tighter `< 5 × mle_seed_sd`) and `|stderror − mle_std_errors| ≤ std_errors_rtol × mle_std_errors`, every number read from the TOML.
  - `newcomb2_rank.toml` (week 2, `rank.deference + rank.nonconformity("localAND") + rank.inconsistency(week 1)`; `test/fixtures/r/newcomb2_rank.R`, ~20 min): one Julia seed at the same budget against `mle_seed_mean` within `coefficient_sd_multiple × √(1 + 1/5) × mle_seed_sd` (one draw against the mean of five) and `mle_std_errors_mean` within `std_errors_rtol`.
  - **Every Monte-Carlo tolerance is built from R's own spread only** — no number measured on ERGMRank goes into an R script or a `[tolerance]` block. The premise is that the two MCMLEs are the same estimator at the same budget, so a Julia estimate is one more draw from ergm.rank's seed-to-seed distribution (√2·sd_R against R's single frozen fit, √(1 + 1/5)·sd_R against the mean of five; the bridges: √2·`mle_loglik_mc_se`). ERGMRank's own 12-seed measurements (seed sds 0.5–1.0× R's, bridge sd 0.061 against R's 0.199) are quoted in the testsets' comments as evidence for the premise, not used. The premise is not asserted because it can only fail safe: were ERGMRank's sd c·sd_R with c > 1, the band would be fewer than 4 sd of the actual difference, so the test fails more often and never hides a disagreement (both fixture scripts say so in a comment). The bridge band 4√2·0.199 = 1.126 replaced 4·(0.199 + 0.061) = 1.039, which used the measured Julia sd (8 % wider, stated in the testset). The multiple is 4; `std_errors_rtol` is 0.15, asserted ≥ 4·√2·max(`mle_std_errors_rel_sd`). **Do not raise any of these numbers**: a failure at 4 means the estimators (or the bridges) disagree, not that a seed was unlucky.
- **`method=:mple` is a DIFFERENT estimator and its gap is CHARACTERISED, never tolerated.** `ergm.rank` fits the MCMC MLE; the swap pseudo-likelihood is not a noisy MLE. The testsets assert the **character** of the disagreement so a change in either direction is noticed:
  - **The observed sufficient statistics match exactly** — deterministic, asserted at 1e-9.
  - **Week 1: the gap is systematic but small.** swap-MPLE `[-0.14091, -0.0058538]` vs ergm.rank `[-0.15310, -0.0065927]`: 16x and 13x `mle_seed_sd` (asserted > 5), 0.30 and 0.43 of an ergm.rank standard error (asserted < 0.6).
  - **Week 2: the gap is large.** 0.89, 0.83 and 0.76 of an MLE standard error (asserted > `mple_gap_min_se` = 0.5), the pseudo-Hessian SEs 3.3×, 2.2× and 2.0× narrower than the MLE's (asserted > `mple_se_ratio_min` = 1.9).
  - **The pseudo-Hessian SEs are anticonservative, by a measured factor:** 3.9x and 2.0x narrower than the MLE's on week 1. `se=:bootstrap` moves most of the way back, and the testset asserts it does.

The README, the estimation guide and the `fit_ergm_rank` docstring all say the same thing: the default reproduces `ergm.rank`; the swap-MPLE does not, by a model-dependent amount.

## Exports: `using ERGMRank` must suffice

The module exports its own API AND the shared verbs a user needs with it: the statistic protocol `compute`/`name` (the ONE `NetworkCore.compute`/`NetworkCore.name`, reached through ERGM.jl — `ERGMRank.compute === NetworkCore.compute` is pinned), the StatsAPI surface, and the result-metadata protocol (`fit_metadata`, `approximations`, `estimand`, `objective`, `is_exact`, `se_method`, `missing_method`). They are the same bindings every fitting package in the ecosystem exports, so co-loading (`using ERGM, ERGMRank, …`) leaves every verb defined and single-owned — pinned in a fresh process by the "using ERGMRank suffices" testset (`ERGM, ERGMRank` always; the rest of the family when the sibling checkouts and the root development environment are present and each sibling loads on its own). Never define a local `compute`, `name`, `gof` or `coeftable`; never `using ERGM: compute` in the docs — it is exported. ERGMRank does NOT re-export NetworkCore: examples that build a `Network` say `using NetworkCore`.

## Conventions

- All term structs subtype `AbstractERGMTerm` and implement `name()` (returning a dotted string like `"rank.mutual.3"`), `compute()` (returning `Float64`) and `swap_change()` (the exact change of a swap, allocation-free; the brute-force oracle is test-only).
- `RankNetwork` stores a dense `Matrix{Int}`; it does not wrap a `Network`.
- Rankings use values `1:(n-1)` per ego where GREATER value = HIGHER standing (matches R ergm.rank; note this is the opposite of "rank 1 = best").
- Functions mutating a `RankNetwork` use the `!` suffix convention (`set_rank!`).
- The module exports all public API symbols explicitly at the top of the module definition.
- Every exported name has a docstring with a runnable `# Example` block (pinned by the docstring-examples testset: every ```julia block of every exported docstring runs after nothing but `using ERGMRank`, **with stderr captured and required empty**, and **every top-level line ending in `# true` / `# false` (optionally `# true: …`) is ASSERTED against its claim** — a comment is a claim, so never write `fit.converged   # true` on a fit that does not converge; use `≈` for a floating-point claim); every README/docs `julia` block executes under `tools/check_snippets.jl`; the docs build is strict (`warnonly=false`, `checkdocs=:exports`), so an exported name with an ERGMRank docstring needs a `@docs` entry under `docs/src/api/`.
- Errors are actionable and name their context: the routine (`as_rank_network:`, `fit_ergm_rank:`, `RankNonconformity:`), the ego at fault, the attribute, the allowed vocabulary. The README's "Common mistakes" section quotes the exact texts; change a message and update it.
- `CHANGELOG.md` is release notes for a first public 0.2.0 (Highlights / Differences from R `ergm.rank` / Known limitations), not a diary: add a one- or two-line note per behavioural change, no development-process references. **"Known limitations" there and "Not implemented" in the README are the same list, item for item** — a testset compares their bold lead-ins.
- `gof(fit)` returns the model statistics AND auxiliary panels (`structural statistics (not in the model)`, `mean received rank (sorted)`, `dyadic rank difference`, `ego agreement (Kendall tau)`, the last only for n ≥ 4). The model statistics of an MCMLE fit are matched by construction; the docstring says so. Each auxiliary is brute-force checked, and the power test (a popularity gradient fitted without it is rejected on the received-rank profile) must keep passing. Draws are ESS-thinned at the default interval (`_simulate_thinned`).
